# Lista soluțiilor de AI

## Înregistrări

### AI-2026-001 — Asistent de cunoștințe Customer Care

| Câmp | Răspuns |
|------------------------------|------------------------------------------------------------|
| **Denumirea** | Asistent de cunoștințe Customer Care |
| **Ce face** | Customer Care, în timpul apelurilor cu clienții: ajută agentul să găsească răspunsul în descrierile produselor și în procedurile publicate pe site-ul Băncii |
| **Tipul AI** | Planificat: AI generativ, abordare RAG |
| **Modul de furnizare** | Dezvoltată intern |
| **Unde rulează** | În discuție — probabil Hibrid: datele stocate local, modelul de limbaj (LLM) accesat prin API |
| **Stadiul utilizării** | Idee — doar în discuție |
| **Pe ce date** | Date publice sau anonimizate. Doar informații publice, disponibile pe site-ul Băncii pentru toți vizitatorii, fără autentificare. Nu se prelucrează informații ce constituie secret bancar |
| **Rolul rezultatului AI** | Recomandă sau fundamentează o decizie a angajatului |
| **Afectează clienții** | Da, indirect |
| **Perioada utilizării** | *Niciuna — idee, nu este încă în uz* |
| **Responsabil** | Departamentul Customer Care Service; persoana nominalizată *încă necunoscută* |
